# Parcial Machine learning. 

Este documento corresponde al desarrollo del Parcial Práctico de Machine Learning del programa de Maestría en Análisis de Datos de la Universidad del Norte, dirigido por el profesor Dr. Lihki Rubio. El objetivo principal es evaluar la capacidad del estudiante para aplicar de manera estructurada técnicas de análisis de datos, modelado predictivo y segmentación de imágenes en distintos contextos.

El parcial se compone de cuatro ejercicios que abarcan:

Análisis exploratorio de datos (EDA): Aplicado a conjuntos de datos de velocidad del viento y detección de fraude, incluye la caracterización de variables, tratamiento de datos faltantes, análisis de simetría, detección de atípicos y reducción de dimensionalidad mediante VIF.

Modelado de clasificación: Implementación de diversos modelos (KNN, Logistic Regression, Random Forest, XGBoost, SVM, MLP, entre otros) para la predicción de fraude, utilizando optimización bayesiana de hiperparámetros y validación cruzada basada en maximizar el AUC.

Modelado de regresión: Aplicación de técnicas de regresión para la predicción de velocidad del viento, considerando la secuencia temporal de los datos, y selección del mejor modelo en función del RMSE.

Segmentación de imágenes médicas: Entrenamiento y evaluación de modelos de segmentación (U-Net, DeepLabV3+, Attention U-Net, entre otros) utilizando métricas específicas de segmentación como Dice, IoU, sensibilidad, AUC y análisis visual de resultados.

Cada sección incluye los resultados, interpretaciones y justificaciones solicitadas, siguiendo el formato de entrega a través de una página web creada mediante Jupyter Book, como fue establecido en las instrucciones.
